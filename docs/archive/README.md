# Archived audit documents

These reports describe the codebase as it stood **before** the cleanup, audio-correctness,
cross-platform and UX work landed on `master`. Most of the problems they raise have since
been fixed, so reading them as a to-do list will send you after bugs that no longer exist.

They are kept for history only. **The current source of truth is [`../BACKLOG.md`](../BACKLOG.md).**

| File | What it was |
|---|---|
| `qa_decentsampler_conformidade.md` | QA pass on `.dspreset` conformance with the Decent Sampler format |
| `avaliacao_servico.md` | General service/product assessment |
| `recursos_backend_nao_utilizados.md` | Inventory of backend features not surfaced in the UI |

If you need a fresh version of any of these, regenerate it against the current code rather
than editing the archived copy.
