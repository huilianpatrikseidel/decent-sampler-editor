# Decent Sampler reference

The target format. Two sources, and they are not interchangeable:

- **[decentsampler-developers-guide.pdf](decentsampler-developers-guide.pdf)** — the
  official developer guide, mirrored from readthedocs. Authoritative for what the format
  offers.
- **[verified-format-notes.md](verified-format-notes.md)** — behaviour we have
  **confirmed in practice**, including cases where the guide is ambiguous and cases
  where the editor got it wrong for a long time. Read this before trusting an assumption
  about how a value is parsed.

The PDF is large; prefer searching `verified-format-notes.md` first, and consult the
guide when the answer is not there — then record what you learned back into the notes.
