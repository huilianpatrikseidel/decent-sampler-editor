# Decent Sampler reference

The target format. Two sources, and they are not interchangeable:

- **[decentsampler-developers-guide-readthedocs-io-en-stable.md](decentsampler-developers-guide-readthedocs-io-en-stable.md)**
  — the same guide as **searchable Markdown**. Grep this first: it is far cheaper to
  search than the PDF and covers the whole format element by element.
- **[decentsampler-developers-guide.pdf](decentsampler-developers-guide.pdf)** — the
  official developer guide as published. Use it when layout or figures matter.
- **[verified-format-notes.md](verified-format-notes.md)** — behaviour we have
  **confirmed in practice**, including cases where the guide is ambiguous and cases
  where the editor got it wrong for a long time. Read this before trusting an assumption
  about how a value is parsed.

Order of consultation: `verified-format-notes.md` for anything we have already confirmed,
then the Markdown guide, and the PDF only if neither settles it. Whatever you learn from
the guide, record back into the notes so the next reader does not repeat the search.
